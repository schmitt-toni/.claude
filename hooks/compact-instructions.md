# Compaction Rules and Guidelines

## Compact Instructions

When summarizing this conversation:

- List every user decision with the chosen option written out in full words (never only a letter
  or number code), the alternatives that were offered and rejected, and the reason if the user
  gave one. A summary that keeps only the choice lets a rejected option come back later as a
  fresh recommendation.
- Keep the user's own wording for constraints ("don't X", "never Y").
- Record something as a user rule or preference only if the user stated it. Mark Claude's own
  assumptions as assumptions, so a guess does not turn into a rule after compaction.
