# Project structure

You are working in a project with dedicated project structure.
Each project is/should be structured the following:
. ~/projects/[project-name]/
| src - Contains repositories in dedicated folders relating to this project
|- [...]
| artifacts - Contains artifacts specific to this project
| docs - Contains non-tracked documentation of this project (meetings minutes, ...)

## Creating artifacts

Create artifacts in the dedicated artifacts folder of the project if it relates to the project. If you are unsure, ask the user.
